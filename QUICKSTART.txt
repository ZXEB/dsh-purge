========================================================================
 dsh-purge 1.1.77  快速开始
 适配 dsh 0.2.2-rc.5（兼容 >=0.2.0-rc.1 <0.3.0）
========================================================================

【最简单的方式：一个网址在 DSH 界面一键安装（推荐）】

  1) 打开 DSH「插件 -> 发现 -> 添加索引源」
     （如果没有「发现」，先到「插件 -> 实验性插件 -> 更多」开启「自定义插件市场 / 自定义插件索引」）

  2) 粘贴下面这行网址并保存：
       https://zxeb.github.io/dsh-purge/index.json

  3) 找到 dsh-purge，点「安装」即可！

  4) 安装完成后：完全退出 DSH（托盘右键退出）并重新打开 ->
     点会话标题旁的 dsh-purge -> 适配 -> 应用 -> 等自动重启 -> 新开一轮对话。


【方式二：直接粘贴安装包网址（DSH 界面「添加插件」或命令行）】

  安装包地址：
    https://github.com/ZXEB/dsh-purge/releases/download/v1.1.77/dsh-purge-1.1.77.tgz

  或命令行（桌面端把 web 换成 desktop）：
    dsh plugin --profile web add "https://github.com/ZXEB/dsh-purge/releases/download/v1.1.77/dsh-purge-1.1.77.tgz"


【方式三：Windows 一键远程安装脚本（免手动下载，带 SHA256 校验）】

  $Installer = Join-Path $env:TEMP ('dsh-purge-install-' + [guid]::NewGuid().ToString('N') + '.ps1')
  Invoke-WebRequest -UseBasicParsing -TimeoutSec 90 -Uri 'https://raw.githubusercontent.com/ZXEB/dsh-purge/master/scripts/install.ps1' -OutFile $Installer
  powershell -NoProfile -ExecutionPolicy Bypass -File "$Installer" -DryRun
  powershell -NoProfile -ExecutionPolicy Bypass -File "$Installer"


【方式四：无网离线安装】

  拷贝 Release 里的 dsh-purge-1.1.77.tgz 到纯英文路径（如 D:\dsh-plugins\），运行：
    dsh plugin --profile desktop add D:\dsh-plugins\dsh-purge-1.1.77.tgz

  或解压源码 zip 到纯英文路径，在该目录运行：
    powershell -ExecutionPolicy Bypass -File .\install.ps1 -Profile desktop


【还原 / 卸载】

  面板里直接点「适配 -> 还原 / 卸载」，或命令行：
    node <DSH_HOME>\profiles\desktop\node_modules\dsh-purge\bin\dsh-purge.js --revert
    node <DSH_HOME>\profiles\desktop\node_modules\dsh-purge\bin\dsh-purge.js --uninstall

  prompt-inject.md / rules / skills 是用户文件，还原和卸载都不会删。
