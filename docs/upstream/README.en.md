# Upstream Archive Note (dsh-purge)

This file is a neutral archive note for the upstream `dsh-purge` documentation. For current installation steps, configuration options, and version compatibility, please see [README.en.md](../../README.en.md) (or [README.md](../../README.md) in Chinese).

## Overview

`dsh-purge` is a local runtime adaptation and prompt management plugin for the official [DeepSeek Harness](https://www.deepseek.com/harness/) installed on your own machine, supporting both official **Web (`dsh web`)** and the official **Desktop app**:

- Applies a reversible patch table for host default settings and prompt segments;
- Provides a side-dock panel for patch status, Apply / Restore / Uninstall, prompt editing, and multiple rule sets (`AGENTS.md` / `CLAUDE.md`);
- Operates strictly on the locally installed `@deepseek-ai/*` packages and local `$DSH_HOME` configuration directory.
