# 0.1.0 验证记录

日期：2026-11-15。

## 自动化验证

使用 Node.js 24.22.1 和官方 `0.2.2-rc.3` Typert Registry / Gateway SDK：**12 / 12 通过**。

- 本地 HTTP 服务的成功、503、302、超时和调用方取消。
- 一次检查只发送一个 GET，不带 Cookie，不跟随重定向。
- URL 协议、嵌入凭据、长度、超时范围校验；结果隐藏查询参数。
- 取消响应正文；诊断能区分已匹配、未知和未验证版本。
- 严格 Remote 元数据与真实 Host 服务相互匹配，拒绝多余和错误参数。
- Gateway 拒绝无权限的测试调用方；并发请求限制、卸载时中止请求有效。
- 浏览器 bundle 可加载、可通过官方 Client Remote 调用 Host、可注册设置页，卸载后清理入口。

## 本机安装与界面验证

通过官方桌面 CLI 的 `plugin --profile desktop add` 安装独立 tarball，命令退出码为 0。

- desktop 启用列表新增 `dsh-local-test`。
- 安装前已有的三个第三方插件依赖值、bundle 顺序和 `cordis.yml` 均完整保留。
- 实际打开桌面 **设置 → 本地测试**，诊断显示 DSH `0.2.2-rc.3`、Node.js `24.21.0`、`win32 / x64`，版本检查为“匹配”。
- 在页面中填写临时本地 HTTP 测试服务地址，点击“开始检查”，通过桌面 Remote / IPC 收到 **HTTP 200，耗时 26 ms**。
- 页面在深色主题下可显示并滚动；输入框使用 `border-box` 避免宽度溢出。

桌面 profile 的包管理器不自动安装宿主提供的 peer，因此 `peers check` 会列出宿主 SDK peer 缺失，包括原有插件的 peer。本次实际 Host 与 Client 加载及 Remote 请求均成功，未通过安装另一份宿主运行时来消除提示。
